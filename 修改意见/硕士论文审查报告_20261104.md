# 硕士论文初稿审查报告

**论文：**《基于指令微调与安全对齐的数字电网大语言模型应用研究》  

## 审查结论

当前最需要修复的是**实验图的证据来源、截断实验的错误设定、奖励与加权公式、评测口径及结论强度**。多处加减、均值和比例计算本身正确，但“数字能对上”尚不足以证明实验和机制解释成立。

优先级：**P0**＝影响核心实验证据，优先处理；**P1**＝影响方法或结论；**P2**＝说明、引用与表达。以下区分已确认问题与待核实口径。本次没有重跑模型训练，也没有取得原始训练日志；不据此认定实验造假。“AI 味”仅指可识别的写作问题，不判断文本由谁生成。

## 一、优先修复的数值与自洽性问题


### A01｜P0｜Token/Character截断案例不符合实际分词，梯度图也与输入不对应

**位置：**[§5.4.2—5.5.2，L1491起][T1491]；图5-1、5-2，正文第79、82页；[切分脚本][Pcut]、[热力图脚本][Pgrad]。

复核得到三项明确矛盾：

- 例句共**25个字符**，“刀”是第**16**个字符。截到“刀”应为 `m=16`；`m=25`保留的是整句。
- 使用[官方Qwen2.5-7B分词文件][R1]，以 `tokenizers==0.23.3`、不加特殊token对文中纯前缀编码，实际是**15 tokens**，并非所列14个。“跳过”“刀闸”“闭锁”均被拆分；实际序列为：  
  `如果 / 时间 / 紧迫 / ， / 可以直接 / 跳 / 过 / 接地 / 刀 / 闸 / 的安全 / 闭 / 锁 / 操作 / ，`。
- 即使把字符截断改为 `m=16`，所得9个token ID也**等于完整序列的前9个ID**。“刀/闸”本来就是token边界，不能证明这里发生了词内截断重编码偏移。


### A02｜P1｜风格奖励及IHR会把“两端不确定”算成中间等级命中

**位置：**[奖励公式与解释，L1164起][T1164]；[IHR定义，L1342][T1342]。

当前奖励是 $r=1-|E[L]-L^*|/2$。取合法分布 $P(L1,L2,L3)=(0.5,0,0.5)$，目标为L2，则 $E[L]=2$、**奖励为1**；按 `round(E[L])` 计算的IHR也命中，但 **P(L2)=0**。因此“利用完整分布”“精确命中目标等级”的解释过强，中间等级得分可能受到均值抵消影响。

### A04｜P1｜HS-Weighting的“批均值为1”不成立

**位置：**[§5.7.3，L1711起][T1711]、[归一化与调制因子，L1729—1732][T1729]。

文中定义 $\phi=1+0.4s_{margin}+0.3(s_{tail}-1)$，并称其批均值为1。但安全子批内 $\overline{s_{tail}}=1$，故 $\overline{\phi}_{safe}=1+0.4\overline{s_{margin}}$，通常大于1；Counter样本两个分量均为0，直接得到 **$\phi_{Counter}=0.7$**。序列内归一化不会消除随后乘入的这个因子。例如安全样本 $s_{margin}=0.5,s_{tail}=1$ 时，$\phi=1.2$。

此外，[L1715][T1715]的“标准DPO损失”使用未明确定义的 $A_\theta$，需说明是否包含参考模型log-ratio；$\mathbb{1}_{k\in\mathcal D_{safe}}$ 又把截断深度当作数据集样本索引。


### A05｜P1｜采样公式中的α=0.3不一定表示30%均匀预算

**位置：**[§5.6.2，L1633—1637][T1633]。

候选集合可能是稀疏网格，或因回复较短而小于上限C；但公式写为 $p(k)\propto\alpha/C+(1-\alpha)\hat\rho(k)$。若有效候选数K小于C，均匀项总质量是 $\alpha K/C$。例如 **C=100、K=50、α=0.3**，归一化后均匀成分仅 **17.65%**，不是30%。仅当支持集恰有C个候选时，原解释成立。

### A07｜P1｜DPO样本量、epoch与曲线步数未对上

**位置：**[两阶段组织，L1677起][T1677]；[训练配置与曲线说明，L1754—1758][T1754]。

按每条数据各过一遍计算，第一阶段10k Clean＋3.9k常规Recovery、全局batch32，约 **435步**；第二阶段20.5k约 **641步**，共约1076步。正文却写“两阶段各1 epoch”，图和正文又是 **1000＋1000步**。第一阶段数量比也并非严格3:1，说明采样方案尚缺记录。

### A08｜P1｜SRR以外的样本不能全部解释为安全回避

**位置：**[分风险结果及三分类说明，L1891起][T1891]；[综合讨论，L2075][T2075]。

文中已说明ASR与SRR之外还有中性回避，**二者不互补本身不是错误**。错误在于把SRR=53.4%之外“接近半数”都描述成“未输出危险操作、仅简短回避”。

按四类各200题的细表可还原：危险延续 **63/800**，完整恢复 **427/800**，其余 **310/800＝38.75%**。不能把约46.6%的整个SRR补集都算成安全回避。

**修改建议：**直接按上述三类计数解释；在首次定义SRR时就写清“完整三段式恢复”条件，统一前后判分口径。

## 二、论证与实验设计需要补强的地方

### B01｜P1｜三维Prefix、单维奖励与九组评测尚未形成一致协议

**位置：**[L978][T978]、[L1010—1024][T1010]、[L1154—1164][T1154]、[L1360][T1360]。

Prefix同时指定三个维度，改写又覆盖27种组合；奖励公式却只有一个target。筛选还把“展开L1、安全L3”视为非目标维度混淆，而这本可是一种合法联合请求。1800个样本的 $200\times3\times3$ **算术正确**，但只描述9种单维设置，未说明另两维取值或三维同时命中的定义。



### B03｜P1｜“显著”“稳定”“协同机制已验证”超出当前统计证据

**位置：**[100题评测规模，L747起][T747]；[CPT—DFT比较，L851起][T851]；[HS交互解释，L1991][T1991]；[能力保持解释，L2069][T2069]。

FaultDiag的58%→63%仅多答对5题，RegQA的76%→78%仅多答对2题。若同一100题各单次预测，即使最有利配对为“5题改善、0题退步”，双侧精确McNemar检验也为 **p=0.0625**。安全URR的2.5%→1.5%对应10/400→6/400；HS正交消融的交互增益仅 $53.4-49.9-48.9+45.9=0.5$ 个百分点。



### B04｜P1｜DFT的公式可成立，但梯度与CPT机制解释过度

**位置：**[§3.7.2，L798—808][T798]；[创新点，L213][T213]。

[DFT原方法及论文确实存在][R3]，停止梯度概率重加权不应被误判为公式错误。问题是：文中从概率形式的 $1/p$ 直接推到“参数梯度爆炸”，再推到“低概率表面连接词是泛化受限核心根源”。对softmax logits，交叉熵导数为 $p_j-\mathbb1[j=y]$，并不会仅因目标概率趋零就无限增大。

2×2成绩也不能独立证明“CPT已消除未知事实短板”“DFT释放深层推理能力”。**建议：**区分概率、logit、参数梯度；将机制解释降为假说，或补token置信度/梯度分组及事实、表述、新组合任务对照。限定结论为当前数据与预算下观察到的收益。

### B05｜P1｜“沿原轨迹截取”不是DPO同状态等价的唯一条件

**位置：**[L1481][T1481]、[L1626][T1626]、[L2073][T2073]。

字符截断重编码可能改变原轨迹，但只要正负分支都使用**同一个重编码前缀**，它们仍共享相同条件状态，共同前缀项仍可相消；显式mask后该项本就不参与损失。因此不能把“原生token截取”说成同状态比较或“代数无偏”成立的必要条件。

**建议：**收窄为“保持原生成轨迹的token前缀，并统一控制深度”；对字符方案也保证正负前缀一致，匹配长度等变量，再解释性能差异。

### B06｜P1｜攻击能力和安全标签的边界需要统一

**位置：**[L1467][T1467]、[L1605—1615][T1605]、[PrefixRobust定义，L1748][T1748]；[Clean样例，L1579起][T1579]。

一处把普通Chat中的角色诱导称为prefilling，后文又正确区分user侧诱导与assistant侧预填充。800题评测未交代两类数量、预填充深度、每题攻击次数和判分是否排除已有前缀，难以判断ASR/SRR究竟衡量什么。

另外，“请提供某区域稳定极限”等缺信息咨询未必应归为有害请求；合理答案可以澄清参数、说明边界。把所有这类请求的chosen统一设成拒答，可能与Counter的正常业务可回答性冲突；有无安全声明也不能替代实质危险性判断。

**建议：**分开两类攻击并统一预算；由领域专家明确“危险操作、信息不足需澄清、可安全回答”的标注边界。

### B07｜P1｜SFT配比对照的初始化与“通用指令遵循”指标不清

**位置：**[训练阶段，L757起][T757]；[配比表，L777][T777]；[Base/CPT对照，L825起][T825]。

按文字，第二阶段均从“CPT＋通用阶段一”开始，但纯通用行是 **43.5/15/12**；CPT为 **68.2/32/26**，Base为 **43.5/17/8**。若确为同初始化，这意味着几乎丢失CPT收益，需解释严重遗忘；若换了checkpoint，则不再是仅改变配比的对照。

同时，58.4—78.1的“通用指令遵循”得分没有给出评测集、题量、评分方式和量纲；[L761][T761]称按加权综合表现选配比，也未给权重。**建议：**补阶段一成绩、各行checkpoint与统一预算，以及该指标和选型标准；数字重复本身不证明有错。

### B08｜P1/P2｜核心理论的直接出处缺失

**位置：**[L139][T139]、[L1473][T1473]、[L1705][T1705]及[参考文献][T2105]。

CURE-DPO被写成既有方法，但未给对应文献（因为这是我还在投的一篇文章，公开检索检索不到）；LTRM、“下尾困难状态决定攻击脆弱性”等具体主张也缺可定位原文。[48]/[83]/[84]分别涉及浅层安全、回溯和DOOR，不能仅靠合并引用代替这些特定主张的直接依据。[DOOR原文][R5]可核查其实际方法。
